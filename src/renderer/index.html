Question Paper Shuffler

Generate multiple sets of a question paper with shuffled questions and options, each with its own answer key.

How to write the Word document so that every question can be shuffled

Do this

  1. Let Word number the questions. Select the questions, then on the Home tab click the numbering button and pick the 1. 2. 3. style. Do not type the numbers yourself — the tool needs Word’s numbering to renumber the shuffled paper.
  2. Let Word letter the options too. Select the four options of a question, click the numbering button and pick a style that shows (A) (B) (C) (D). This one habit makes the most difference: options lettered by Word can always be shuffled.
  3. If you prefer to type the letters, put the letter at the start of the line and press the Tab key after it — never spaces. When two options share a line, press Tab before the second label as well. A row of spaces used to push it across the page looks the same as ordinary text, so where the first option ends cannot be worked out.
  4. Give every question exactly four options, each label used once and no fifth option. The labels may be letters (A) (B) (C) (D), digits (1) (2) (3) (4) or roman numerals (i) (ii) (iii) (iv) — the tool works out which the paper uses. Use the same one throughout.
  5. Keep each option on one line. Do not press Enter in the middle of an option.
  6. If a question also has lettered statements (A. B. C. …), keep the options in brackets — (A) (B) (C) — so the two lists can be told apart.
  7. Put the subject name on a line of its own, in capitals: PHYSICS, CHEMISTRY, BIOLOGY. Nothing else on that line. Questions are only shuffled within their own subject.
  8. Number the questions straight through the paper (1 to 180). Do not start again at 1 for each subject.
  9. In the answer key table, put the question number in one box and the answer in the next box. Write the answer however your paper writes it — A, (A), a, 1, 2. or iii) — and the tool writes the new answer back the same way. Use one style for the whole key. The number may be written 1, 1. or 1); all three are read.

Avoid this

  1. Options inside a table. Those cannot be shuffled. Put each option on its own line instead. A table inside the question is perfectly fine.
  2. A picture anchored to the wrong question. A floating picture is drawn downwards from the paragraph it is anchored to, and Word attaches that anchor to whichever paragraph was nearest when you dropped the picture — often the last line of the previous question. Those two questions then have to stay next to each other, so both are kept in their original positions and listed in the dry run. To free them, click the picture and drag its anchor marker into the question it illustrates, or set Layout Options to In line with text.
  3. A picture in the middle of an option’s words. A floating picture is placed from the page, so it stays put while the words move. A diagram sitting beside or between the options is fine — the answers are shuffled around it and the question is listed for you to check. Only a picture wedged between the words of one answer stops that option moving. If a picture belongs to one particular option, select it and set Layout Options to In line with text.
  4. Options that point at other options — “Both (A) and (B)”, “None of these”. Shuffling can change what they mean. If you use them, type those question numbers into Keep the option order of these questions. Assertion-Reason questions are fine as long as each option says what it means (“Only statement I is true”); only printing that wording once as directions above, and leaving the options as bare numbers, causes trouble.
  5. Brackets taken from a picture font — Wingdings or Webdings in Insert → Symbol. Those fonts hold drawings rather than letters, so a bracket picked from one looks right on screen but says nothing about what it is, and the tool cannot see where one option ends and the next begins. Delete the label and type (A) again with the keyboard. A bracket from the ordinary Symbol font, which is what Insert → Symbol offers first, is read correctly and needs no change.
  6. A stray character in an answer key number box — 57, where 57. was meant. That box no longer names a question, so the key comes up one answer short. The tool says which box it is; retype it as the plain number.

Nothing is ever guessed at. Anything that cannot be read with certainty is listed by Dry run and left exactly as it was, with its answer letter unchanged.
